# \# El Oasis

# 

# Aplicación web desarrollada como proyecto colaborativo durante el primer curso del CFGS de Desarrollo de Aplicaciones Web (DAW).

# 

# El proyecto consiste en una aplicación para la gestión de un bar, con una parte pública para consultar la carta y realizar reservas, y un panel de administración desde el que gestionar los productos y sus precios.

# 

# 

# \## Tecnologías utilizadas

# 

# \- Java

# \- JSP y Servlets

# \- MariaDB

# \- HTML5

# \- CSS3

# \- JavaScript

# \- JSTL

# 

# \## Funcionalidades

# 

# \### Parte pública

# 

# \- Consulta de la carta de comida y bebidas.

# \- Visualización de los productos con nombre, descripción, precio e imagen.

# \- Formulario para realizar reservas.

# \- Información de contacto del establecimiento.

# 

# \### Panel de administración

# 

# \- Inicio de sesión para acceder al panel de administración.

# \- Visualización de todos los productos registrados.

# \- Creación de nuevos productos.

# \- Selección de categoría: comida o bebida.

# \- Subida de imágenes asociadas a los productos.

# \- Actualización del precio de los productos.

# \- Eliminación de productos.

# 

# \## Base de datos

# 

# La aplicación utiliza MariaDB para almacenar y gestionar la información de los productos.

# 

# \## Mi participación

# 

# El proyecto fue desarrollado de forma colaborativa entre los cuatro integrantes del equipo, participando todos en las diferentes fases del desarrollo.

# 

# Mi principal área de trabajo fue el backend, especialmente el desarrollo con Java, Servlets y programación orientada a objetos. También participé en la conexión y gestión de la base de datos, el desarrollo de los DAO y la implementación de las operaciones CRUD.
